# יבוא חד פעמי — חנות הזמנות בוואטסאפ

אתר קטלוג בעיצוב "צ'אט וואטסאפ" ללקוחות שלכם. הלקוח גולל, לוחץ "הוסף", ובסיום לוחץ "שליחת הזמנה בוואטסאפ" — נפתחת שיחת וואטסאפ עם המספר העסקי שלכם, עם הודעה מוכנה מראש שמפרטת את כל הפריטים, הכמויות והמחיר הכולל. **בלי צורך באישור/גישה למטא (WhatsApp Business API)** — זה עובד עם כל מספר וואטסאפ רגיל, דרך קישור `wa.me`.

בנוסף, **כל הזמנה, לקוח ופרטי מלאי נשמרים במסד נתונים** (SQLite מקומי) — כך שיש לכם תיעוד מלא, גם אם ההודעה בוואטסאפ "הולכת לאיבוד". יש מסך ניהול (`/admin`) שבו ניתן לראות הזמנות, לקוחות, לעדכן סטטוס הזמנה ומלאי, ולשנות הגדרות.

## הרצה מקומית

```bash
npm install
cp .env.example .env
npx prisma db push   # יוצר את קובץ מסד הנתונים המקומי
npm run seed          # מאכלס נתוני דוגמה (קטגוריות + מוצרים)
npm run dev
```

האתר יעלה בכתובת http://localhost:3000, ומסך הניהול בכתובת http://localhost:3000/admin (סיסמת ברירת מחדל: `admin123`).

## הגדרה ראשונית — חשוב לפני שמשתפים לקוחות!

1. היכנסו ל־`/admin` → לשונית **הגדרות**.
2. עדכנו את **מספר הוואטסאפ העסקי** שלכם, בפורמט בינלאומי ללא `+` וללא `0` מוביל (למשל מספר ישראלי `050-1234567` הופך ל־`972501234567`).
3. עדכנו את שם החנות, הודעת הפתיחה, ואת **סיסמת הניהול** (שווה להחליף מ־`admin123`).
4. בלשונית **מלאי** אפשר לערוך מחירים, כמות במלאי, ולסמן מוצר כ"אזל".

> ⚠️ עד שלא תעדכנו את מספר הוואטסאפ, הזמנות ישלחו למספר דמה (`972500000000`).

## עריכת קטלוג המוצרים

נתוני הדוגמה הראשוניים נמצאים בקובץ `prisma/seed.ts`. אפשר:
- לערוך שם/כמות/סטטוס מלאי דרך מסך הניהול (`/admin` → מלאי).
- או לערוך את `prisma/seed.ts` ולהריץ שוב `npm run seed` (שימו לב: זה מוחק הזמנות ולקוחות קיימים ומתחיל מחדש — מומלץ להשתמש בזה רק בשלב ההקמה).

להוספת מוצרים/קטגוריות חדשות בלי למחוק נתונים קיימים — ניתן להוסיף זאת ישירות דרך Prisma Studio:

```bash
npx prisma studio
```

## איך זה עובד מתחת למכסה

- **Next.js (App Router) + TypeScript + Tailwind** לחזית ולשרת.
- **Prisma + SQLite** (`prisma/dev.db`) לשמירת כל הנתונים: מוצרים, קטגוריות, לקוחות, הזמנות, פריטי הזמנה, הגדרות חנות.
- כשלקוח שולח הזמנה: קודם היא **נשמרת בשרת** (`POST /api/orders`), ורק אז נפתח קישור `wa.me/<מספר>?text=<הודעה מעוצבת>` בטאב חדש — כך גם אם הלקוח לא שולח בפועל את ההודעה בוואטסאפ, ההזמנה כבר נשמרה אצלכם במערכת.
- מסך `/admin` מוגן בסיסמה (עוגיית session מוצפנת), ומאפשר צפייה ועדכון הזמנות/מלאי/הגדרות.

## פריסה לאינטרנט (כדי שלקוחות יוכלו להזמין מהטלפון)

האתר בנוי כאפליקציית Next.js רגילה וניתן לפרוס בכל פלטפורמה שתומכת ב־Node.js (Vercel, Railway, Render וכו'). שימו לב: כברירת מחדל המידע נשמר בקובץ SQLite מקומי — בפריסה לענן מומלץ לעבור למסד נתונים מנוהל (למשל Postgres) כדי שהנתונים לא יימחקו בכל דיפלוי. אם תרצו עזרה בהגדרת פריסה מלאה עם דומיין, ספרו לי ואני אעשה את זה בשבילכם.
